# CrackNEET — Store Listing Draft

## Short description
NEET & JEE Main practice with statement, assertion-reason, numerical and conceptual questions.

## Full description
CrackNEET is an exam-practice app designed for NEET and JEE Main aspirants.

Practice with:
- Statement-based questions
- Assertion–Reason questions
- Numerical questions
- Conceptual questions
- Subject and chapter-based practice
- Explanations after questions

NEET subjects: Physics, Chemistry, Biology.
JEE Main subjects: Physics, Chemistry, Mathematics.

The current question bank contains original questions written in common PYQ-style formats; it does not claim to reproduce official PYQs verbatim.
