# CrackNEET — Official PYQ Sources

CrackNEET uses official NTA NEET question-paper archives as the source reference for PYQ ingestion.

## NEET 2020 archive

Official NTA archive:
https://neet.nta.nic.in/document-category/archive/page/7/

Available sets on the referenced archive page include:
- English Set E1, E2, E3, E4, E5, E6
- English Set F1, F3, F4, F5, F6
- English Set G1

Each listed paper links to an NTA-hosted PDF.

## Data policy

Questions must be transcribed/structured from the source paper and verified against the corresponding official answer key where available. The app must not label generated or reconstructed questions as official PYQs unless they can be traced to a source paper.

Question records should retain:
- exam
- year
- paper/set
- subject
- chapter (only when reliably classified)
- question type
- question
- options
- correct answer
- explanation/source note
